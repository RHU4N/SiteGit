# 🌍 Projeto Volta ao Mundo

> **Objetivo Principal:** Praticar o **versionamento de código** e o **trabalho colaborativo** utilizando **Git e GitHub** em um projeto de desenvolvimento web integrado.

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido para a disciplina de Desenvolvimento Web (Fatec - 6º Semestre). Mais do que a construção das páginas em si, **o foco central da atividade foi o treino prático de Git**, abrangendo:
* **Trabalho Colaborativo:** Divisão de tarefas entre os membros da equipe em um repositório compartilhado.
* **Histórico de Commits:** Registro frequente e semântico das alterações e evolução de cada página.
* **Padronização de Código:** Uso de um layout base (`index.html` com `iframe`) e um CSS global compartilhado entre todos os integrantes.

---

## 🛠️ Tecnologias e Ferramentas

* **Git & GitHub:** Controle de versão, gerenciamento de branches, commits e colaboração em equipe.
* **HTML5:** Estruturação semântica e carregamento dinâmico via `iframe`.
* **CSS3:** Estilização global com Flexbox, variáveis nativas (`:root`) e responsividade.

---

## 📂 Estrutura do Repositório

```text
/

├── css/

└── pages/              # Páginas desenvolvidas individualmente pelos membros
    ├── home.html
    ├── america.html
    ├── europa.html

    ├── africa.html
    └── oceania.html

```
